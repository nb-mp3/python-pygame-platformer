# Python Pygame Platformer
A retro-inspired 2D platformer developed using Python and Pygame as part of my Computer Science NEA.

This project involves developing a 2D platform game where players navigate levels, avoid obstacles and use projectile-based combat to defeat enemies.

The game was developed through an iterative process, with regular testing, debugging and feedback from stakeholders.

## Features

- Player movement and jumping mechanics

- Gravity and collision detection

- Projectile-based combat

- Enemy interactions

- Health and scoring systems

- Multiple levels with increasing difficulty

- Interactive menus

## Technologies used

- Python

- Pygame

## What I learned

Through this project, I developed my programming and problem-solving skills, including:

- Implementing game mechanics and handling player input

- Using collision detection and game logic

- Debugging and testing software

- Breaking a large project into smaller components

- Using stakeholder feedback to improve a product

## Running the project

1. Install Python.

2. Install the required dependencies using pip install -r requirements.txt.

3. Run the game using python main.py.
